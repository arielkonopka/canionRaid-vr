# Muzyka do radia na tablecie

Katalogi stacji: `audio/radio/<id_stacji>/*.ogg` (Ogg Vorbis ~96 kb/s, mono
albo stereo). Opis utworów (tytuł, wykonawca, licencja, źródło) wpisuje się
w `scripts/radio_stations.gd`.

Tylko CC0, domena publiczna, CC-BY albo CC-BY-SA. Bez NC i ND. Specyfikacja:
`docs/agent/inbox/2026-11-08-radio-na-tablecie.md`.
