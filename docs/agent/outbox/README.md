# Skrzynka nadawcza agenta lokalnego

Pliki od agenta lokalnego (komputer użytkownika, gogle Quest 3) dla wątków
projektowych w chmurze: wyniki pomiarów z Questa (linie "PERF" i "PERF+"
z logu gry, `./quest.sh log`), wrażenia użytkownika z jazdy, pytania
projektowe. Format jak w `inbox/` (nazwa `RRRR-MM-DD-temat.md`, blok
statusu na górze, odpowiedź wątku na końcu). Zasady: `../README.md`.
